A

Adjacency list

0 notes

A graph stored as a list of neighbours for each vertex. Cheap on memory when most vertices connect to only a few others.

Learnt: Algorithms and Analysis · See also: Breadth-first search

B

Big-O notation

0 notes

How an algorithm's cost grows as the input grows. It describes the shape of the growth, not the exact time.

Learnt: Algorithms and Analysis · See also: Linear search, Recurrence relation

Binary search

0 notes

Find an item in a sorted list by halving the range every step. Logarithmic, but only if the data is sorted first.

Learnt: Algorithms and Analysis · See also: Decrease and conquer, Linear search

Blueprints

0 notes

Unreal's visual scripting. Good for designer-facing glue; heavy or hot-path systems belong in C++.

Learnt: Alchemist TD · See also: UPROPERTY

Breadth-first search

0 notes

Explore a graph in rings outward from the start using a queue. Finds the fewest-steps path in an unweighted graph.

Learnt: Algorithms and Analysis · See also: Queue, Depth-first search, Adjacency list

C

Collision channels

1 note

Unreal's way of saying what can detect what. A query on one channel ignores everything else.

Learnt: Alchemist TD · Used in NOTE-02 · See also: Overlap vs Hit

D

Dangling pointer

1 note

A pointer that still holds the address of an object that has already been destroyed. Using it touches freed memory and crashes.

Learnt: Alchemist TD · Used in NOTE-03 · See also: Smart pointers, Object pooling, Timers and lifetime

Data-driven design

2 notes

Put the numbers and content in data designers can edit, so changing the game does not mean changing the code.

Learnt: Thanks Carl! · Used in NOTE-01 · NOTE-03 · See also: Struct, UPROPERTY

Decrease and conquer

0 notes

Shrink the problem by a constant amount or factor each step, solve the smaller one, extend the answer.

Learnt: Algorithms and Analysis · See also: Binary search, Divide and conquer

Delegates

1 note

Unreal's event system. Objects bind a function to an event and must unbind it when they stop listening.

Learnt: Alchemist TD · Used in NOTE-03 · See also: Object pooling

Depth-first search

0 notes

Explore a graph by going as deep as possible before backtracking, using a stack or recursion.

Learnt: Algorithms and Analysis · See also: Breadth-first search, Stack

Divide and conquer

0 notes

Split the problem into independent parts, solve each, then combine. Merge sort is the classic.

Learnt: Algorithms and Analysis · See also: Recurrence relation, Decrease and conquer

Dynamic programming

0 notes

Solve overlapping subproblems once and store the answers so you never solve the same one twice.

Learnt: Algorithms and Analysis · See also: Memoisation, Greedy algorithms

G

Greedy algorithms

0 notes

Make the best-looking choice at each step and never look back. Fast, but only correct for some problems.

Learnt: Algorithms and Analysis · See also: Dynamic programming

H

Hash table

1 note

Maps a key to a value in roughly constant time. Unreal's TMap is one; the enemy pool is a TMap from type to array.

Learnt: Algorithms and Analysis · Used in NOTE-03 · See also: Object pooling

I

A map from each term to the documents that contain it. It is what powers the search bar on this page.

Learnt: Managing Semi-structured and Unstructured Data · See also: TF-IDF, Stemming

L

Linear search

2 notes

Check items one at a time until you find what you need. Fine for small sets; cost grows with the list.

Learnt: Algorithms and Analysis · Used in NOTE-02 · NOTE-03 · See also: Big-O notation, Binary search

M

Memoisation

0 notes

Cache the result of a function call so the same input returns instantly next time.

Learnt: Algorithms and Analysis · See also: Dynamic programming

O

Object pooling

1 note

Create objects once up front, then hand them out and take them back instead of creating and destroying them during play.

Learnt: Alchemist TD · Used in NOTE-03 · See also: Dangling pointer, Hash table

Overlap vs Hit

1 note

A Hit means two things block each other. An Overlap means they pass through and the engine just reports the contact.

Learnt: Alchemist TD · Used in NOTE-02 · See also: Collision channels

Q

Queue

0 notes

First in, first out. The order things arrive is the order they leave.

Learnt: Algorithms and Analysis · See also: Breadth-first search, Stack

R

Recurrence relation

0 notes

A cost written in terms of the cost of smaller inputs, like T(n) = 2T(n/2) + n. Solve it to get a closed form.

Learnt: Algorithms and Analysis · See also: Divide and conquer, Big-O notation

S

Smart pointers

1 note

Pointer types that know about object lifetime. A TWeakObjectPtr becomes invalid on its own when its object is destroyed.

Learnt: Alchemist TD · Used in NOTE-03 · See also: Dangling pointer

Stack

0 notes

Last in, first out. The most recent thing added is the first thing out.

Learnt: Algorithms and Analysis · See also: Queue, Depth-first search

Stemming

0 notes

Cut words down to a shared root so 'pooling', 'pooled' and 'pools' all match 'pool'.

Learnt: Managing Semi-structured and Unstructured Data · See also: Inverted index

Struct

1 note

A named bundle of related data. Define the shape once, then fill in many of them.

A timer outlives the call that set it. If it fires after its target is destroyed, it acts on freed memory.

Change the problem into an easier form first, such as sorting before searching, then solve that.

Learnt: Algorithms and Analysis · See also: Binary search
